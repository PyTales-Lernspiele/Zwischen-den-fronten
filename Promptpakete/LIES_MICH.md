# Promptpakete/ — historisch, nicht mehr benutzen

Bis zum 4. September 2026 wurde jedes Paket als eine vollständige
Textdatei in Claude Code hineinkopiert: Verfassung, Auftrag und Abnahme
in einem Stück, für jedes Paket neu.

Seitdem liegt der Auftrag im Projekt selbst:

```
CLAUDE.md                    wird beim Start automatisch gelesen
auftrag/VERFASSUNG.md        das Dauerhafte
auftrag/ENTSCHEIDUNGEN.md    was bindend entschieden ist
auftrag/PAKETPLAN.md         Reihenfolge und Stand
auftrag/OFFENE_PUNKTE.md     was noch aussteht
auftrag/paket05.md … 10.md   die Aufträge
```

**Die Dateien in `Promptpakete/` sind der Beleg, wie es dazu kam** — sie
enthalten eine ältere Fassung der Verfassung, die an einigen Stellen
überholt ist (unter anderem fehlen ihr die Regel 11 und die
Handwerksregeln g und h). Wer sie liest, liest den Stand vom Vortag.

Maßgeblich ist `auftrag/`. Bei Widerspruch gewinnt immer `auftrag/`.
